EDLs

Sem funcionalidade nesta etapa. A API Conta Ovos documenta endpoints de EDL, mas nenhum foi validado, sincronizado ou homologado no Endemias ainda.

Sera adicionado como nova aba deste centro somente quando houver uso confirmado no setor, contrato de API validado, schema e migracao proprios, e sincronizacao GET supervisionada — pelo mesmo criterio usado para Ovitrampas.

Quarteirões e ações

Sem funcionalidade nesta etapa. Quarteirões, geometria e composição territorial têm como fonte de verdade local o GeoJSON e o Registro Geográfico; a API pode ser vinculada a eles, mas nunca deve sobrescrevê-los.

Envio de ações (TBO) por /postaction depende de validar antes: vínculo entre quarteirão local e block_id remoto, tipos de imóvel, unidade de larvicida e semana epidemiológica do servidor. Nenhum desses pontos foi validado neste lote.
